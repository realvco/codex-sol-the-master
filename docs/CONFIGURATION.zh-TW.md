# 設定說明

<p align="center">繁體中文 · <a href="./CONFIGURATION.md"><strong>English</strong></a></p>

## 正式指令對應

目前公開契約如下：

```text
有請高手處理      ->  sol_high   ->  gpt-5.6-sol / high
恭請高高手處理    ->  sol_xhigh  ->  gpt-5.6-sol / xhigh
```

上方空格只是為了方便閱讀；實際暗號是完整片語，不要求前後空白。中文暗號使用
「有請」與「恭請」以及「高手」與「高高手」的多重差異，必須依完整字串逐字比對，
不依賴視覺相似度或語意推測。

## 如何選擇層級

使用 `sol_high` 處理邊界清楚的實作或診斷，例如重現錯誤、追查根因、修改幾個
相關檔案、補測試或檢查一個明確範圍的變更。

使用 `sol_xhigh` 處理具有架構取捨、資料遷移、跨模組依賴、高風險資料變更或
需要額外驗證回合的任務。兩個層級同時指定給同一項任務，或任務邊界不清時，
也以優先級較高的 `sol_xhigh` 為準。

`high` 與 `xhigh` 表示推理深度，不是速度開關。兩個 Sol Agent 都不得主動要求
Fast；若客戶端沒有提供可觀測的 service-tier 證據，必須回報「未觀測到」，不
能把推定寫成已驗證。

## 安全安裝順序

把範例複製到真實 Codex Home 前，依序完成：

1. 確認目前使用的 `$CODEX_HOME`，並記錄 `codex --version`。
2. 檢查目前 Codex 版本支援的 Agent TOML schema 與自訂 Agent 開關。
3. 盤點既有的 `AGENTS.md`、`AGENTS.override.md`、`agents/` 與路由標記；不要
   覆寫無關區塊。
4. 備份每一個目標檔案，且把備份放在公開 repository 之外。
5. 只套用獲得授權的最小 diff，保留所有無關設定。
6. 開啟新的 Codex task，依照[測試說明](./TESTING.zh-TW.md)執行正向、負向、
   碰撞與回到預設測試。

不要自行猜測並加入 `service_tier = "standard"`。如果目前版本沒有公布可驗證的
標準 tier ID 或局部 Fast-off 機制，就省略該欄位並回報限制；不能因為看不到 Fast
就宣稱已確定使用 Standard。

## 個人 Codex 目錄

概念上的個人安裝位置如下：

```text
$CODEX_HOME/
├── AGENTS.md
└── agents/
    ├── sol_high.toml
    └── sol_xhigh.toml
```

本 repository 使用 `$CODEX_HOME` 佔位符，不包含任何真實使用者路徑。安裝前請
確認目前環境的 Codex Home，並先備份現有設定。

## Agent 檔案

範例定義：

- `sol_high`：`gpt-5.6-sol`、`high`。
- `sol_xhigh`：`gpt-5.6-sol`、`xhigh`。

兩份範例都不得設定 `service_tier = "fast"`。不同客戶端可能只顯示父代理 tier、
子代理 tier，或完全不提供 tier 遙測；測試報告要保留這個差異。

## 路由規則

路由是自願啟用、單次任務：

1. 完整暗號必須作為使用者的主動指令出現。
2. 將目前完整任務交給指定的自訂 Agent。
3. 不得由主代理模仿子代理，也不得靜默替換其他 Agent。
4. 等待子代理回報，再把控制權交回主代理。
5. 下一項任務必須再次輸入完整暗號。
6. 若同一任務同時出現多個有效暗號，只使用 `sol_xhigh`，不要重複執行。

## 不應觸發的情況

以下內容都不會啟動子代理：

- 解釋、引用、翻譯或編輯暗號的要求。
- 否定句、只輸入片段，或標點／大小寫變形。
- 只說「請深入分析」、「使用更強模型」、「使用 Sol」或「加快速度」。
- 任務本身很難、檔案很多、風險很高，但沒有完整暗號。

如果使用者只輸入暗號，卻沒有明確的未完成任務，不得建立空白子代理；應請使用
者在同一則訊息提供要處理的任務。

## 失敗與回復

如果自訂 Agent 無法建立、模型／推理強度無法選取，或速度邊界無法驗證，必須
回報實際原因。不得靜默改用其他 Agent、降低推理強度、啟用 Fast，或聲稱子代理
完成了實際上沒有完成的工作。

子代理完成、失敗、受阻、被中止或 Thread 關閉後，該次暗號授權立即結束；後續
新任務回到 App 選定的主代理設定，並需要重新輸入完整暗號才能再次委派。
